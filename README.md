## 📜 The 1Files Manifesto

1. **One file per application:** All markup, styles, JavaScript logic, SVG icons, and audio synthesis are bundled inline within a single `.html` document.
2. **Zero external requests:** The application must boot and remain fully functional on an air-gapped machine with network interfaces disabled.
3. **Permanent durability:** Standard web standards only (HTML5, CSS3, ES2022, Web Audio API, Web Crypto API) to guarantee identical rendering decades into the future.

---

## 🚀 Air-Gapped & Offline Operational Instructions

To run any application offline or in an air-gapped environment:
1. **Download:** Click any application link above or click the **Download** button in the [vault portal](https://lin4cre.github.io/1files/#vault) to save the `.html` file.
2. **Transfer:** Save the `.html` file to a USB flash drive or air-gapped workstation.
3. **Execute:** Double-click the `.html` file in any modern browser (Chrome, Firefox, Safari, Edge).
4. No internet connection, server runtime, or npm build dependencies are required. All computations and crypto primitives execute 100% client-side in browser memory.
